# 160x128 color

20 columns x 10 rows of 8x12 px. UPPERCASE = 2x font (16x24, 10 characters per line). Example boards: DM-1701, MD-UV380, MD-9600.

## Home, idle, DMR

```
┌────────────────────┐
│IDLE DMR ▮▮▮ ✉2 84% │ status strip (8x8 font)
│Local repeaters     │ zone
│03 COUNTY D…        │ channel, 2x (middle-ellipsized)
│                    │
│PTT→ TG 3100        │ talk target, 2x-ish (12x16 font)
│USA  TS1 CC1 Hi     │ chips as text
│────────────────────│
│Q1AAA Joe · TG91 2m │ last heard, one line
│OK Menu *Quick #Joe │ hint row
└────────────────────┘
```

## M17 (an M17 channel; [m17.md](../m17.md))

Home, idle (gallery `home_m17`):

```
┌────────────────────┐
│[IDLE] M17   ▮▮▮ 84%│
│Local repeaters 3/16│
│3 COUNTY DMR        │ LARGE
│→All call           │ the destination; "→No M17 callsign" in warn without one
│1W CAN0 3200 W1AW   │ chips: power, CAN and rate, Priv, Sig, our callsign dim
│────────────────────│
│N0CALL       Sig OK │ the last M17 call: caller and signature word
│All call     11s ago│ line 2, dim
│Hold OK save Back un│
└────────────────────┘
```

Receiving (`home_m17_rx`, `home_m17_rx_signed`):

```
┌────────────────────┐
│[RX]  84%  To you   │
│N0CALL              │ LARGE
│via M17-M17 C       │
│"Hello from Lisbon" │
│Signed: checked at …│
│CAN0 3200    -71 dBm│
│PTT replies         │
└────────────────────┘
```

Transmitting (`home_m17_tx`):

```
┌────────────────────┐
│[TX]     All call   │
│TALKING             │ LARGE, TX color; SIGNING during a signed call's tail
│From W1AW           │
│CAN0 3200           │
│0:01 of 3:00        │
│Release PTT to stop │
└────────────────────┘
```

Call Details (`call_details`): From, the signature word, To, CAN, Voice, Encryption, Text, Position, Signer, Signed
to, Signed at, Time check, Signal, Heard; labels dim, scrolled with Up / Down.

BER test (`m17_bert`): the state large in its color (Locked green, Lock lost warn), "BER 0.012%" large, errors,
frames and the signal, hint "PTT send  OK reset  Back".
