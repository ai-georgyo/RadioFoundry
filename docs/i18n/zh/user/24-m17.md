# M17

M17 是面向业余无线电的开放数字语音与数据模式。电台以呼号而不是号码来识别。语音使用开放的 Codec 2 声码器，因此 M17
不需要原厂固件中的声码器。

并非每款电台都运行 M17，也并非每个版本都包含 M17 的所有部分（签名、加密、短消息、已听到列表、误码率测试）：见[各电台上的
M17](23-radios.md#m17-on-each-radio) 和[功能矩阵](../feature-matrix.md)。M17 尚未与其他 M17 电台或热点互通测试。

在电台频率编辑器中编写 M17 信道、你的呼号、密钥和电台密钥（[为电台编程](04-programming.md#m17)）。在电台上也可以设置呼号、通话文本、CAN
和语音速率。

## 你的呼号

在 M17 上按 PTT 需要你的呼号。没有呼号时电台显示 **未设置 M17 呼号**；此时按 **OK** 即可输入。也可以在 **设置 > 我的电台 >
M17 呼号** 中设置。如果电台频率中的电台名是有效呼号，在你设置呼号之前会使用它。

<img src="../ux/screens/160x120i5/callsign.png" width="200" alt="输入呼号">

- 呼号最多 9 个字符：A-Z、0-9、`-`、`/` 和 `.`。**1** 键输入 `- / .`，**0** 键输入空格。
- 必须以字母或数字开头。
- **M17 通话文本**（我的电台）随每次通话发送，最多 52 个字符。

## M17 信道与 VFO

| 位置 | 方法 |
|---|---|
| 已存储的 M17 信道 | 来自电台频率编辑器、共享的区域，或任何信道：在其**模式**上按 **OK** 直到显示 M17，然后保存（[编辑信道](07-channels-zones-vfo.md#editing-a-channel)） |
| VFO | **\***、**4** 切换 VFO 的模式：FM、DMR，然后在支持的电台上是 P25、NXDN 和 M17（“VFO：M17”）（[VFO 中的 M17](07-channels-zones-vfo.md#m17-in-the-vfo)） |

VFO 和新建的 M17 信道从 **设置 > 通话与收听 > M17 CAN** 和 **M17 语音** 开始，目标为 **全呼**，加密关闭。

### CAN

信道接入号（CAN，0-15）把同一频率上的不同群组分开，类似 DMR 的色码。电台播放其信道 CAN 上的通话。**数字监听**（快捷
**5**）播放所有 CAN 上的通话。信道的 CAN 也可以设为 **Any**（接收所有 CAN，发送时用自己的 CAN）。其他 CAN 上的通话显示
**其他 CAN：未播放**。

### 语音速率

**3200 bit/s** 是完整质量的语音。**1600 bit/s + 数据** 把语音速率减半，在码流中留出数据空间；本电台在其中不发送数据，收到的数据也不显示。

## 主屏幕与通话

| 位置 | 显示 |
|---|---|
| 通话行 | 目标：**全呼** 或一个呼号 |
| 标签 | 功率、`CAN0 3200`（信道接入号与语音速率）、信道加密时显示 **加密**、签名通话时显示 **Sig**、你的呼号 |
| 接收时 | 大字显示呼叫方，然后是目标（发给你时显示“发给你”）、经由的中继或服务器、通话文本、距离（有 GPS 定位时）以及签名的状态词 |
| 通话之后 | 最后的呼叫方及其签名的状态词。**#**、**3** 打开 **通话详情** |

<img src="../ux/screens/160x120i5/home_m17_rx_signed.png" width="200" alt="带签名的通话">

电台不播放的通话会说明原因：**已加密：不播放**、**Scrambler：未播放**、**其他 CAN：未播放** 或 **仅数据：无语音**。

**通话详情** 显示上一次通话的全部内容：谁呼叫、呼叫谁、CAN、语音速率、通话文本、位置；对于签名通话，还有签名电台、签名时间和时间确认。

### 签名

签名通话可以证明是哪个电台发出的。通话结束时，电台用你的 **电台密钥** 中发送方的公钥检查签名。

| 状态词 | 含义 |
|---|---|
| Sig OK | 签名与发送方的密钥一致 |
| Sig 失败 | 不一致。横幅会提示；**#** 打开详情 |
| 来自 W1AW | 由呼叫方以外的电台签名。横幅会提示。“最近”中显示“其他电台” |
| 过时 | 签名一致，但按电台的时钟，签名时间相差超过 5 分钟 |
| 重复 | 签名与电台之前接受过的通话相同：一段被重新播放的录音 |
| 有 Sig：无密钥确认 | 你没有发送方的密钥 |
| 未确认：加入过晚 | 你在通话开始之后才加入 |
| 未确认：数据不全 | 通话的一部分丢失，无法检查签名 |
| 确认中 | 通话已结束，电台正在检查，需要片刻 |
| 无 Sig | 来自你持有其密钥的电台的未签名通话 |

来自你没有其密钥的电台的未签名通话不显示状态词：大多数 M17 通话都没有签名。

**签名时间。** 电台关机后不保留时钟。只有在有 GPS 定位（或由电脑设置时间）时它才知道时间，这时 **通话详情** 对签名时间显示
**时间有效** 或 **过时**。没有时钟时，电台从不判断签名通话是新的还是过时的：**时间确认：未确认：无时钟**。没有时钟的发送方不发送时间：
**Sig 时间：未发送**。

要为你的通话签名，请打开 **设置 > 加密 > M17 通话加 Sig**。它需要电台频率编辑器中的签名密钥。**M17 Sig 密钥** 显示其识别码；请与编辑器中的比对。
**M17 电台密钥** 列出你持有的密钥。共享的区域绝不会带来电台密钥或签名密钥：任何人都能发送区域，因此电台只信任你在电台频率编辑器中添加的密钥。签名不隐藏任何内容，因此在业余频段上是允许的。它会在每次通话末尾增加一小段尾部。

### 加密

M17 信道可以用扰码（Scrambler）或 AES 加密其通话，密钥来自电台频率编辑器。信道编辑器中的 **加密** 打开或关闭它；密钥及其类型由编辑器设置。
加密的信道在主屏幕上显示 **加密**，**加密**（快捷 **6**）可将其关闭。电台只有持有信道的密钥时才播放加密通话；否则显示
**已加密：不播放** 或 **Scrambler：未播放**。设为加密的信道从不以明文发送：在不含加密功能的版本中，PTT 会被拒绝。

大多数国家禁止在业余频段上发送为隐藏含义而编码的信息。**业余** 版本不包含扰码和 AES（[安装](02-installing.md)）；签名保留。

### 音频

M17 语音使用 Codec 2 声码器。语音和双音多频按键音可以正常传递。持续的纯音（持续数秒的单一音调，例如测试音）会弱几个分贝。

## 与电台通话

目标就是 M17 的通话目标。长按 **#**（或 **快捷 8**）打开选择器：**全呼**、最近听到的电台，以及 **输入呼号...**。主屏幕上
**#**、**1** 回复最后的呼叫方。

- 在 VFO 上，或临时切换为 M17 的信道上，目标是临时的：主屏幕上按 **返回** 撤销。
- 在已存储的 M17 信道上，电台不保留临时目标。在某个电台上按 **OK** 会显示 **长按 OK 设置**；长按 **OK** 把该电台设为信道的目标。
- 目标也可以是服务器的模块（`M17-M17 C`）或 `ECHO` 这样的命令。
- 输入呼号“ALL”会被拒绝。要呼叫所有人，请选择 **全呼**。

## M17 的快捷设置

| 按键 | 磁贴 |
|---|---|
| 1 | 功率 |
| 2 | 速率：3200 或 1600 bit/s |
| 3 | CAN，0-15 |
| 4 | 到 VFO（在 VFO 中为模式） |
| 5 | 数字监听：播放所有 CAN |
| 6 | 加密：关闭加密 |
| 7 | 双守候 |
| 8 | 通话目标（目标） |
| 9 | 亮度 |

在已存储的 M17 信道上，CAN、速率和数字监听在信道编辑器中设置（**请在信道编辑器中设置**）。在已存储的信道上关闭加密会写入该信道。

在临时切换为 M17 的信道上，CAN、速率和数字监听只是临时的（**CAN 3 （临时）**）：在主屏幕上按 **返回**，或换到另一个信道，即可撤销。在 VFO 中，CAN 和速率是 VFO 自己的，与 **设置 > 通话与收听** 中的相同。

## 信道编辑器

M17 信道有 **CAN**（0-15，或 **Any**）、**速率**、**目标**（选择器，或输入呼号）和 **加密**（开或关；密钥及其类型来自电台频率编辑器）。保存会写入信道。

## 设置

| 组 | 设置 |
|---|---|
| 通话与收听 | **M17 CAN** 和 **M17 语音**：VFO 及新建 M17 信道的设置 |
| 加密 | **M17 通话加 Sig**、**M17 Sig 密钥**、**M17 电台密钥** |
| 位置 | **M17 通话中发送**：GPS 有定位时，随通话发送你的位置 |
| 我的电台 | **M17 呼号**、**M17 通话文本** |

查找可以找到所有这些设置：输入“M17”。各行见[设置](17-settings.md)。

## 消息

M17 消息（短消息）与其他消息一起出现在 **消息** 中（[消息](10-messages-and-signaling.md#m17-messages)）。**新 M17 消息**
向你输入的呼号发送一条消息。请从 M17 信道发送。电台会等信道空闲后再发送。M17 没有送达回执：电台显示 **已发送至** 或 **未发送至**，从不显示“已送达”。
电台保留最近 4 条消息（收到的和发出的），直到关机；超过 143 字节的消息会被截断。

- M17 消息从不加密。设为加密的信道（主屏幕显示 **加密**）不发送消息：其消息行变暗并显示 **加密已开：消息无法加密**。请关闭 **加密**，或从其他信道发送。

## 扫描与双守候

扫描会在 M17 信道上停下，并在你会听到的通话上保持（信道的 CAN，或开启数字监听时的任何 CAN）。双守候可以把 M17 信道作为 A 或 B；其窗格显示呼叫方（[扫描与双守候](12-scan.md)）。

## 工具

- **已听到**：最近听到的电台，最新的在前，每个显示多久以前、多少次以及最近一次签名的状态词。**OK** 显示其中一个，**#**
  打开其操作（与其通话、给它发消息）。目前 M17 是它唯一的来源。
- **M17 BER 测试**：此信道上 M17 测试信号的误码率，用于检查链路或电台。**PTT** 发送测试码型，**OK** 重置计数。页面显示
  **搜索中**、**已锁定**、**失锁** 或 **无信号**，以及误码率和计数。仅在 M17 信道或 M17 模式的 VFO 上可用。
